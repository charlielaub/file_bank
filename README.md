# File Bank for Charlie Laub
**I store various files in this repository related to my work in audio and loudspeakers.**

## DFE Crossovers:
This folder has docs related to the Derived from Elliptic crossover filters that I developed. I originally published the work in audioXpress in September 2024. 
There is a file that is hosted by aX that is too large to include here. It has complete details about the DFE crossovers and can be found here:
[The DFE Crossover Family - Complete Information](https://audioxpress.com/files/attachment/2777)

## Minimally Baffled Dipole Loudspeakers
This folder contains files related to open baffle loudspeakers that have very small to no baffle area. 
These generally have a dipole radiation characteristic over a very wide frequency band. 
I published an article in audioXpress describing the theory and motivation behind this type of loudspeaker, and an example of how to build one.  

## Groundplane Measurement Techniques
This folder contains a whitepaper that describes some new ways to make groundplane measurements, including a new technique called 
Measure, Move-Move, Measure as well as how to correct measurement for non-ideal groundplane reflectivity. This can permit measurements to be 
made on outdoor surfaces such as grass or other flat ground that is not normally considered acoustically reflective.
